# TaskTimer — 自作タスク時間計測アプリ

Pixel 9a 用のネイティブ Android アプリ。標準タイマーの使いづらさを解消し、
既存の「MacroDroid + Notion 時間計測システム」をアプリとして作り直す。

---

## このフォルダの使い方

1. このフォルダをまるごと Claude Code に渡す（フォルダを開いて `claude` を起動）
2. 最初に「`README.md` と `CLAUDE.md` を読んで、Phase 0 から始めて」と伝える
3. Claude Code が `docs/` を読んで実装を進める

**Android Studio がまだ入っていない場合は、先に [`docs/04_SETUP.md`](docs/04_SETUP.md) を見てセットアップしてください。**
Claude Code に「`docs/04_SETUP.md` の手順を一緒にやって」と頼んでも進められます。

## 一言でいうと

> タスクを始めるとき「ゴール」と「予定時間」を宣言する。
> 予定時間が来たら**全画面で強制的に**「延長するか、終えるか」を選ばされる。
> 逃げられない。だから必ず記録が残る。

## v1 のスコープ（最初に作るもの）

- ✅ タスクの開始／切り替え（前のタスク完了 ＋ 次のタスク開始が 1 アクション）
- ✅ タスク名は**使用頻度順のクイック選択** ＋ 自由入力
- ✅ ゴール・予定時間の宣言
- ✅ **通知バー常駐**（経過時間・ゴール・切り替えボタン）
- ✅ 予定時間到達 → **バイブ ＋ 全画面表示 ＋ オーバーレイブロック**
- ✅ 超過画面：ゴール再掲・超過率・延長プリセット選択 → **合計所要時間が 1 か所で更新**
- ✅ 評価（◯/△/✕）と理由メモ
- ✅ 履歴・日別／タグ別集計
- ✅ **ローカル完結**（Notion 同期なし）

## 重要な設計判断（決定済み・変更する場合は要相談）

| 項目 | 決定 |
|---|---|
| 技術スタック | ネイティブ Android（Kotlin + Jetpack Compose） |
| 同時実行タイマー数 | **1 個のみ**。時間は途切れず連続して記録される |
| 常時表示 | v1 は通知常駐のみ。ウィジェットは v2 |
| 強制力 | フルスクリーン表示 ＋ オーバーレイブロック |
| アラーム | **バイブのみ**（音は鳴らさない。音楽を聴きながら使う想定） |
| プリセット並び | 使用頻度で自動並び替え |
| 延長プリセット | 固定初期値あり ＋ ユーザー編集可 |
| データの正 | v1 はアプリ内 Room DB が唯一の正 |
| 配布 | Play ストアには出さない。自分の Pixel 9a にサイドロード |
